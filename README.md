Hit & Blow

概要
C言語とncursesライブラリを用いて開発したHit & Blowゲームです。
プレイヤーは重複しない数字列を予想し、正解との一致度を示す「Hit」と「Blow」を手掛かりに正解を導きます。
コンソール上で快適にプレイできるよう、カラー表示やメニュー画面、ヘルプ機能を実装しました。

工夫した点

1. 入力チェック
以下の場合はエラーになるよう実装しました。
桁数不足
数字以外の入力
数字の重複
また、不正入力が3回続くとゲームを終了します。

2. 視認性の向上
ncursesのカラー機能を利用し、
Hit → 緑色
Blow → 黄色
エラー → 赤色
で表示しています。
さらに文字を中央付近に配置し、見やすい画面構成を意識しました。

3. 保守性の向上

機能ごとに関数を分割し、
数列生成
入力処理
判定処理
エラー処理
を独立させることで可読性を向上させました。
